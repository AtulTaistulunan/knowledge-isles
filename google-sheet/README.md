# 知識群島：把學生的作答記到 Google 試算表

學生玩遊戲時，每次預測、作答、完成實驗站、破島，都會在試算表裡多一列。
設定只要做一次，大約 5 分鐘。

## 一、建立試算表和程式

1. 到 Google 雲端硬碟，新增一份 **Google 試算表**，例如命名為「知識群島作答紀錄」。
2. 在試算表上方選 **擴充功能 → Apps Script**，會開一個新分頁。
3. 把編輯區原本的內容全部刪掉，貼上同一個資料夾裡 **`Code.gs`** 的全部內容。
4. 按上方的 💾（儲存專案）。

## 二、部署成網頁應用程式

1. 按右上角藍色的 **部署 → 新增部署作業**。
2. 「選取類型」旁的齒輪 ⚙ 選 **網頁應用程式**。
3. 設定：
   - 說明：隨意，例如「作答紀錄」
   - **執行身分：我**
   - **誰可以存取：所有人**（學生不用登入就能送出作答；他們只能新增資料，看不到試算表）
4. 按 **部署**。第一次會要求授權：選你的帳號 → 「進階」→「前往（未安全）」→ 允許。
   （這是 Google 對自己寫的程式的固定警告，程式只會寫入這一份試算表。）
5. 複製 **網頁應用程式的網址**（`https://script.google.com/macros/s/……/exec`）。
6. 用瀏覽器打開這個網址，看到「知識群島作答紀錄：運作中」就是成功了。

## 三、把網址填進遊戲

打開遊戲資料夾裡的 **`record.js`**，找到這一行：

```js
var ENDPOINT = '';
```

把網址貼在引號中間，存檔。所有島（物理、數學、藝術、地理）都會用這個網址。

> 也可以把網址傳給 Claude，請它幫你填。

## 試算表的欄位

第一次收到資料時會自動建立「作答紀錄」工作表：

| 欄位 | 說明 |
|---|---|
| 時間 | 學生電腦上的作答時間 |
| 班級座號 | 例如 901-05（遊戲開始時學生自己填，不會送出名字） |
| 島 | 各島的名稱，例如 力與運動實驗島、地名郵差：臺灣地名島 |
| 實驗站 | 實驗站名稱（地理島是空白） |
| 類型 | 預測／測驗／完成／破島；地理島是 送信／地標／時光機／破島 |
| 題目／項目 | 題目文字，或送信的地名 |
| 回答 | 學生選的選項，或信送到哪裡 |
| 對錯 | ✓／✗（預測、完成、地標沒有對錯） |
| 第幾次嘗試 | 這一題在這一輪是第幾次作答（答對後重新算） |
| 第幾輪 | 這個學生第幾次進這個實驗站（「再玩一次」也算新的一輪） |
| 花費秒數 | 測驗：這一題想了幾秒；完成：這一站花了幾秒 |
| 紀錄編號 | 系統用來避免重複記錄，不用理它 |

## 常用的看法

- **誰卡住了**：篩選「對錯 = ✗」，看哪些班級座號、哪一題錯最多次。
- **迷思概念**：篩選「類型 = 預測」，看每個實驗站學生的預測分布。
- **整體進度**：篩選「類型 = 破島」或「完成」。
- 用 **插入 → 資料透視表**：列放「題目／項目」、值放「第幾次嘗試」的平均，就能看出哪一題最難。

## 注意事項

- 沒網路時，作答會先存在學生的瀏覽器裡，連上網後自動補送。
- 之後如果修改了 `Code.gs`，要用 **部署 → 管理部署作業 → ✏ 編輯 → 版本：新版本** 重新部署，網址才會維持不變。
- 想重新開始收資料：把「作答紀錄」工作表改名或刪掉，下次收到資料會自動建立新的。
